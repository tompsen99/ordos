# 纺织品配比计算工具

一个优雅的纺织品配比计算和可视化工具，帮助用户找到最优的无毛绒混合方案。

## 功能特点

- 批次数据管理
  * 添加、编辑、删除批次信息
  * 记录长度、细度、重量、价格等属性
  * 数据本地持久化存储
  * 自动计算并显示批次等级
  
- 智能配比计算
  * 自动计算最优混合方案
  * 支持多批次混合
  * 支持混合批次的二次混合
  * 生成多种配比建议
  * 计算混合后的等级

- 可视化展示
  * 清晰的数据输入界面
  * 直观的拖拽混合操作
  * 专业的配比结果展示
  * 详细的混合建议报告
  * 等级标签直观显示

- 分组管理功能
  * 创建批次分组
  * 保存配比方案为分组
  * 显示分组混合结果和等级
  * 分组的选择和删除操作

- 数据导入导出
  * 导出全部数据
  * 导出批次数据
  * 导出历史记录
  * 支持数据导入恢复

- 历史记录管理
  * 自动保存配比历史
  * 收藏重要配比方案
  * 应用历史配比设置
  * 管理历史记录

## 数据管理

### 本地存储
- batches: 批次数据
- batchGroups: 分组数据
- mixingHistory: 配比历史
- parameterPresets: 参数预设

### 数据格式
- 批次数据：包含长度、细度、重量、价格等属性
- 分组数据：包含批次ID、混合比例、结果等
- 历史记录：包含完整的配比方案和结果

### 等级判定

系统根据以下参数自动判定等级：
- 长度 (mm)
- 细度 (dtex)

支持的等级系列：
- G系列 (G1-G6)
- J系列 (J0-J5)
- A系列 (A01-A08)
- B系列 (B1-B7)
- C系列 (C1-C43)
