# 纺织品配比计算工具

一个优雅的纺织品配比计算和可视化工具，帮助用户找到最优的无毛绒混合方案。

## 功能特点

- 批次数据管理
  * 添加、编辑、删除批次信息
  * 记录长度、细度、重量、价格等属性
  * 数据本地持久化存储
  
- 智能配比计算
  * 自动计算最优混合方案
  * 支持多批次混合
  * 支持混合批次的二次混合
  * 生成多种配比建议

- 可视化展示
  * 清晰的数据输入界面
  * 直观的拖拽混合操作
  * 专业的配比结果展示
  * 详细的混合建议报告

## 页面结构

### 1. 批次管理页面 (index.html)
- 批次数据表格
- 添加/编辑批次表单
- 批次筛选和搜索

### 2. 配比计算页面 (mixing.html)
- 批次选择区域
- 拖拽混合界面
- 实时计算结果
- 保存混合方案

### 3. 建议报告页面 (report.html)
- 多种配比方案展示
- 详细参数对比
- 导出报告功能
